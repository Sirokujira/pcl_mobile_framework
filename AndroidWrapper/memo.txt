Android での Native Library Wrapper を作成する際の手順について

0. 空の app 作成。
   参照 : https://techbooster.org/android/18043/

1. Android Sutdio のメニューから File->New->New Module を選択して ライブラリを作成する。
   ※ Folder 構成 : (appフォルダ名)/(ライブラリ名)
   ※ ライブラリ名に "_" は使用しない。(_1 になるためバグの温床になりやすいので)(-にする？)

2. Appveyor の Artifacts から バイナリをダウンロードして ライブラリフォルダの libs フォルダに解凍する。
   (フォルダ構成は、
    (対象 arch)/(module名)/include
    (対象 arch)/(module名)/lib

3. ライブラリ

4. CMakeLists.txt にリンクを設定。

4. 必要があれば app/build.gradle に 対象 arch の Filter を追加する。
   参照 : https://developer.android.com/studio/projects/add-native-code
   ※ なるべくなら、5個全部用意しておく。

5. メニューから build -> make
